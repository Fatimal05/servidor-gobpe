Prototipo Web GOB.PE

Proyecto académico de Programación Web que simula una plataforma de consulta de trámites del Estado peruano.

Tecnologías utilizadas

HTML5 y CSS3

Bootstrap 5

JavaScript

Node.js y Express

Funcionalidades

Interfaz web adaptable.

Formulario de consulta de trámites.

Validación de campos vacíos.

Comunicación entre frontend y backend mediante una API REST.

Control de acceso mediante una clave de demostración.

Cómo ejecutar el proyecto

Descargar el repositorio.

Abrir la carpeta del proyecto en Visual Studio Code.

Ejecutar npm install en la terminal.

Ejecutar node server.js.

Abrir http://localhost:3000 en el navegador.

Nota: Prototipo desarrollado únicamente con fines académicos.
